# Карточка товара «Ананасовый улун» — тестовое задание для Teaboom.ru

**Результат:** https://teaboom-case.vercel.app/

Верхняя часть карточки товара интернет-магазина чая: галерея фото, категория, название,
выбор фасовки, цена со скидкой, кнопка «В корзину» и короткое описание.

Без фреймворков и сборщиков: HTML + SCSS (собирается sass'ом) + ванильный JavaScript.

## Что внутри

- **Фасовки** 100 г / 500 г / 1000 г / 5000 г — плитки-радиокнопки. При переключении меняются
  цена, старая цена, скидка, артикул и наличие. Данные лежат в `data-`атрибутах радиокнопок,
  поэтому без JavaScript страница остаётся рабочей.
- **Галерея** — главное фото и миниатюры, клик по миниатюре плавно меняет кадр. Активная
  плитка помечается `is-active` и `aria-current="true"`.
- **Лайтбокс** на нативном `<dialog>`: клик по фото открывает текущий кадр во весь экран,
  закрывается крестиком, кликом по подложке или Esc. Фокус-ловушка и возврат фокуса —
  нативные, своего кода почти нет.
- **Кнопка «В корзину»** — жёлтая «пилюля» как на teaboom.ru, при клике на пару секунд
  уходит в «Добавлено». Самой корзины нет — по условию задания она не требуется.
- Изменения озвучиваются скринридерам через `aria-live`, видимый фокус везде,
  учитывается `prefers-reduced-motion`.

## Запуск

Нужен локальный сервер — скрипт подключён как ES-модуль и по `file://` не заведётся. Проще
всего через OpenServer (проект уже лежит в `domains/teaboom-case`) или Live Server в VS Code.

```bash
npm install
npm run build:css    # scss -> assets/css/style.css
npm run watch:css    # пересборка при изменениях
npm run format       # prettier по html/scss/js/json/md
npm run check:js     # node --check по скрипту
```

